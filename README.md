## Features

- **6DOF gun combat**: aim with the controller, with 1:1 iron sights.
- **6DOF gesture-based melee**: swing the left controller for a Quick Attack. Hold LT while swinging for a Heavy Attack and gun combat.
- **Occulobe Enhancement System (R3)**: switches weapon aim from the right controller to the HMD.
- **Peek HUD**: hold the right thumbrest to show the UI, and release it to hide the UI.
- **Psygate**: hold both thumbrests.
- **Gesture D-Pad**: hold the right thumbrest and move the controller up, down, left or right to press that D-Pad direction. Holding RB does the same thing.
- **Tunable haptics** for in-game actions and events. Turn off the in-game Controller Rumble setting.
- **Right stick tuning**: smoother turn acceleration for player rotation. Keep the in-game controller sensitivity at the default **30%**.

## Controls (Quest)

### Left Controller

| Input | Action |
|---|---|
| Left Stick | Move player, navigate menus |
| Grip | Block |
| Trigger | Hold to charge Power Attack |
| X | Ability 1 / Cancel |
| Y | Ability 2 |
| B + Y | Ability 3 |
| L3 | Click to sprint, hold for Start |
| Menu | Pause menu |

### Right Controller

| Input | Action |
|---|---|
| Right Stick | Rotate player left/right |
| Grip (hold) | Comms menu: use the right stick to choose an order. When ordering Brother Nahum to heal, gesture down or up with the right controller to heal either him or Brother Barachiel. |
| Trigger | Fire weapon |
| A | Interact / Confirm |
| B | Reload |
| R3 | **Click:** activate the Occulobe Enhancement System (aim switches to HMD)<br>**Hold:** reset helmet position<br>**Click:** toggle Main Menu visibility |
| Thumbrest | **Hold:** show HUD<br>**Hold + gesture up/down/left/right:** D-Pad<br>**Hold both thumbrests:** Psygate |

## Notes

- The Occulobe Enhancement System (R3) currently has no zoom and no visual enemy identification aid.
- Only the Steam version is supported.
- The Map Screen does not show map geometry. This may not be fixable.
- The right arm and pauldron meshes are hidden. They clipped into the view, and a Space Marine couldn't see their own pauldrons or most of their arms anyway.
- **No crosshair:** the in-game crosshair is unreliable, and I haven't been able to get a good version working. Almost every weapon in the game is hip-fired anyway. The gun mesh is aligned with the shot direction so the iron sights are reliable, and the Occulobe Enhancement System covers most cases where a crosshair would have helped.
